# Prism Plus icon generation brief

The master bitmap was created with OpenAI's built-in image-generation mode using this exact
prompt:

> Use case: logo-brand
>
> Asset type: 1024x1024 master artwork for a native macOS application icon
>
> Primary request: Create a polished icon for “Prism Plus,” a dedicated local LaTeX editor that
> transforms source code into beautiful PDF documents.
>
> Subject: A crisp white document/page with a subtly folded corner, intersected by a small elegant
> triangular prism that refracts a narrow beam into a restrained teal, cyan, blue, and violet
> spectrum. Include a minimal abstract typesetting cue made from two or three clean mathematical
> glyph-like strokes, but no readable letters or words.
>
> Style/medium: premium macOS productivity-app icon, clean dimensional vector-like 3D finish,
> refined rather than playful
>
> Composition/framing: centered, bold silhouette, generous safe margin, immediately legible at
> 16–32 px; artwork contained inside a softly rounded square icon tile
>
> Lighting/mood: subtle depth, soft inner highlights, calm professional creative-tool mood
>
> Color palette: midnight navy and charcoal background, white paper, luminous teal-to-violet
> accents
>
> Materials/textures: smooth glass prism, lightly satin paper, very subtle shadow
>
> Constraints: exact square composition; no text, no brand names, no watermark, no tiny details,
> no busy background, no photorealistic scene, no Apple logo; keep essential artwork within the
> central 80 percent; suitable for conversion to all Apple app icon sizes
>
> Avoid: generic rainbow, excessive gradients, neon overload, pencils, code brackets, literal
> PDFs, mockup environment
